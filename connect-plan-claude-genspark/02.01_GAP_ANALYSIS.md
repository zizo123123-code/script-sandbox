## 🔴 النواقص الحرجة

### GAP-01: مفيش آلية "حجز نية" قبل بدء الشغل
- **المشكلة:** العزل الحالي يمنع التعارض في *الكتابة*، لكن مفيش حاجة تمنع
  أيجنتين ياخدوا **نفس المهمة** في نفس اللحظة (T-005 مثلاً) — هيشتغلوا
  بالتوازي على نفس الحاجة ويضيعوا مجهود مضاعف.
- **الحل المعتمد:** 🐜 **لوحة الفيرومونات** (`pheromones/`) — إشارة `CLAIM`
  بصلاحية زمنية (TTL) قبل بدء أي مهمة. تفاصيل في `02.00_SWARM_DNA_PROTOCOL.md`.
- **المهمة:** T-013

### GAP-02: مفيش بروتوكول تعافي (Recovery) لو أيجنت بوّظ الريبو
- **المشكلة:** الخطة بتقول "ممنوع --force" بس مفيش خطوات موثقة لو حصل
  commit غلط على main أو ملف اتمسح بالخطأ.
- **الحل المعتمد:** قسم "🚑 التعافي" في `PROTOCOL.md`:
  `git revert` (مش reset) + تسجيل الحادث في `SESSION_LOG.md` + فيرومون `WARN`.
- **المهمة:** T-003 (توسيع معيار القبول)

### GAP-03: مفيش سياسة أسرار (Secrets Policy)
- **المشكلة:** `PROMPT_TEMPLATE.md` فيه متغير `{GITHUB_TOKEN}` — لو أيجنت
  حطه في ملف واترفع، التوكن اتسرب للأبد في git history.
- **الحل المعتمد:** قاعدة ذهبية جديدة (رقم 7): "التوكن يعيش في البيئة فقط
  (env var) — أي ملف فيه token = رفض فوري" + توسيع `.gitignore`
  (`*.token`, `*.secret`, `.env*`).
- **المهمة:** T-003 + T-004 (توسيع)

## 🟡 النواقص المهمة

### GAP-04: مفيش معيار موحد لنسب الـ Commits للأيجنتات
- **المشكلة:** إزاي نعرف من git history إن الـ commit ده من AG ولا DS؟
  الاعتماد على الرسالة النصية هش وغير قابل للفلترة الآلية.
- **الحل المعتمد:** **Git Trailers** إلزامية في كل commit:
  ```text
  Agent-Code: AG
  Task-ID: T-005
  Based-On: 01.04_DS_agent_mode.py
  ```
  دي قابلة للقراءة الآلية بـ `git log --format="%(trailers:key=Agent-Code)"`
  وهي أساس حساب السمعة (GAP-07).
- **المهمة:** T-003 (إضافة للبروتوكول)

### GAP-05: مفيش طابور قرارات موحد لزيزو
- **المشكلة:** القرارات المطلوبة من زيزو (زي قرار T-010) متناثرة جوه
  الملفات — سهل تضيع.
- **الحل المعتمد:** ملف `DECISIONS_QUEUE.md` — طابور واحد بكل قرار معلق:
  رقم + سؤال + خيارات + توصية + خانة رد. زيزو يفتح ملف واحد ويرد.
- **المهمة:** T-014

### GAP-06: بروتوكول المنظومة نفسه مش مُنسَّخ (No Protocol Versioning)
- **المشكلة:** لو عدلنا `PROTOCOL.md` بعد ما أيجنتات حفظته، هيحصل
  انقسام: كل أيجنت شغال بنسخة مختلفة من القواعد.
- **الحل المعتمد:** حقل `protocol_version: 1.0` في `AGENTS.yaml` + أول سطر
  في `PROTOCOL.md` — والأيجنت ملزم يقارن النسخة اللي يعرفها بالموجودة
  ويعيد القراءة لو اختلفت.
- **المهمة:** T-002 + T-003 (توسيع)

### GAP-07: مفيش قياس جودة/ثقة للأيجنتات
- **المشكلة:** كل الأيجنتات متساوية للأبد — مفيش وسيلة موضوعية نعرف بيها
  مين بيسلم شغل نضيف ومين بيكسر البروتوكول.
- **الحل المعتمد:** 🏆 **سجل الثقة (Trust Ledger)** — سمعة محسوبة آلياً
  من git history. تفاصيل في `02.00_SWARM_DNA_PROTOCOL.md`.
- **المهمة:** T-015 (مرحلة V0.15)

## 🟢 التحسينات

### GAP-08: شجرة تطور الكود مش مرئية
- **المشكلة:** `# Based-on:` موجود جوه الملفات بس مفيش صورة كلية —
  عايز تعرف شجرة عائلة السكربتات لازم تفتح كل ملف.
- **الحل المعتمد:** 🧬 **شجرة الجينوم** — أداة `dna_tree.py` تبني مخطط
  Mermaid تلقائي من رؤوس الملفات. تفاصيل في `02.00_SWARM_DNA_PROTOCOL.md`.
- **المهمة:** T-016 (مرحلة V0.15)

### GAP-09: مفيش فحص صحة ذاتي للمنظومة
- **المشكلة:** مين يكتشف إن أيجنت نسي يحدث PROGRESS أو سمى ملف غلط؟
- **الحل المعتمد:** أداة `doctor.py` — فحص شامل بأمر واحد:
  التسمية، الرؤوس، الفيرومونات المنتهية، تحديث PROGRESS، صلاحية YAML.
- **المهمة:** T-017 (مرحلة V0.15)

### GAP-10: مفيش وضع عمل منقطع (Degraded Mode)
- **المشكلة:** لو أيجنت مش قادر يعمل push (زي جلستنا دي!) الشغل يضيع؟
- **الحل المعتمد:** قاعدة "Commit محلي دايماً حتى لو Push فشل" + ملف
  `OUTBOX.md` في غرفة الأيجنت يسجل فيه إن فيه commits مستنية رفع —
  أول جلسة تلاقي اتصال ترفعهم.
- **المهمة:** T-003 (إضافة للبروتوكول)
