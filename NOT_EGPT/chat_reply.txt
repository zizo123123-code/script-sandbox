## ☕ قصة مضحكة: "المبرمج اللي من غير قهوة"

كان في مبرمج اسمه **محمود**، شغال في شركة برمجيات، وموهوب جدًا... بس عندو مشكلة واحدة: **مينفعش يشتغل قبل ما يشرب قهوته**.

كل يوم الصبح كان بييجي الشغل، يفتح اللابتوب، ويبص في الكود بتاعه... فيلاقي كل حاجة مظبوطة! بس لما يضغط Run، يطلعله ٤٠ إيرور من غير سبب. يقول "مستحيل! الكود ده كان شغال إمبارح!"، يفضل يراجع السطر ألف مرة، يغير أسماء المتغيرات، يحذف فنكشنات، يزود print هنا وهناك... ومفيش فايدة.

فجأة، يسمع صوت زميله بيقولو: "محمود! انت لسه ماشربتش قهوة النهاردة؟"

محمود يقوم نط، يقول: "صدقني انت صح!"

يروح يعمل قهوة تركية سخنة، يقعد، يشرب نص كوب، ويرجع للكود... يدوس Run... **يشتغل من أول مرة! 🎉**

الكل مصدوم، يقولوله: "ازاي يا محمود؟ كنت بتصلح إيه؟"

قالهم بكل برود: "والله أنا ملقتش ولا غلطة! الكود كان تمام. المشكلة إن عيني كانت واقفة... والقهوة هي اللي بتحل المشاكل."

ومن النهاردة، كل واحد في الشركة قبل ما يشتكي لأي إيرور، بيقول: "روح اشرب قهوة الأول يا محمود!"

## 🐍 كود بايثون بسيط لشرب القهوة

```python
class Coffee:
    def __init__(self, cups=1):
        self.cups = cups
        self.caffeine = 0

    def drink(self):
        if self.cups > 0:
            self.cups -= 1
            self.caffeine += 50
            print("☕ شربنا فنجان قهوة... إحنا دلوقتي في تركيز كامل!")
        else:
            print("😵 خلصت القهوة! الكود هيبوظ النهاردة... لازم نعمل غيرها")

    def refill(self):
        self.cups += 1
        print("🫖 عملنا قهوة جديدة... حياة كريمة!")

    def is_awake(self):
        return self.caffeine >= 100


# محاكاة يوم مبرمج حقيقي
meh = Coffee(cups=2)

meh.drink()      # ☕ أول فنجان
meh.drink()      # ☕ تاني فنجان

if meh.is_awake():
    print("💻 دلوقتي أقدر أكتب كود من غير إيرورات... إن شاء الله!")
else:
    meh.refill() # لو لسه مش صاحي، نعمل تالتة
```
