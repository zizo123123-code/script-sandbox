# 🚀 Master Git Sandbox Prompt Template — برومبت الأيجنت القياسي للتعاون على GitHub

> **الهدف:** قالب برومبت قياسي جاهز للإرسال لأيجنت الساندبوكس في NoteGPT أو أي أيجنت سحابي، لضمان سحب الريبو كامل، تعديل الملف المطلوب فقط، واستخدام بروتوكول `git pull --rebase` الآمن لمنع أي تعارض على فرع `main`.

---

## 📋 البرومبت الجاهز للنسخ:

```text
المستودع: https://github.com/zizo123123-code/script-sandbox.git
التوكن: ghp_YOUR_GITHUB_TOKEN_HERE

المهمة المطلوبة منك في الساندبوكس:
1. استنسخ المستودع بالكامل وافحص ملفاته لفهم سياق المشروع.
2. قم بتنفيذ التعديل التالي فقط:
   - [اكتب هنا اسم الملف والمطلوب تعديله بالضبط، مثلاً: عدل ملف 1111 واكتب فيه نكتة جديدة]

تعليمات الرفع والتعاون الآمن (Strict Rebase Protocol):
- عدّل الملف المطلوب فقط وتجنب لمس أو تعديل أي ملفات أخرى في المستودع.
- قبل الرفع، نفّذ دائماً أمر: `git pull --rebase origin main` لسحب أي تعديل جديد من الأطراف الأخرى وتركيب تعديلك فوقه.
- ارفع التعديل إلى فرع main مباشرة باستخدام: `git push origin main` (ممنوع نهائياً استخدام --force).
- في حال تم رفض الرفع بسبب تزامن، أعد المحاولة تلقائياً بـ `git pull --rebase` ثم الرفع.
- اطبع في تقريرك النهائي: رقم الـ Commit، واسم الملف المعدل، ورابط التعديل على GitHub.
```
